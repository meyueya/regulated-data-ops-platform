# Arco operativo V1–V5

| Versión | Capacidad funcional | Evidencia profesional |
| --- | --- | --- |
| V1 — Ingesta | Contrato, idempotencia, cuarentena y lineage | Data Engineering |
| V2 — Confianza | Reglas configurables, SLO y evolución de esquema | High-Risk Data |
| V3 — Operación | FastAPI, autenticación y dashboard | Full Stack |
| V4 — Regulación | RBAC, retención, cifrado y policy-as-code | Cybersecurity |
| V5 — Inteligencia | Diagnóstico multiagente y recuperación supervisada | AI Architecture |

## Puerta de promoción

Una versión solo avanza cuando mantiene contratos anteriores, prueba éxito,
rechazo y reintento, actualiza amenazas, produce una demo reproducible,
registra decisiones en un ADR y recibe aprobación humana.
